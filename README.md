## 常见问题

**家宽 VPS 和普通韩国 VPS 到底差在哪？**
差在 IP 类型标签。普通韩国 VPS 用机房 IP，在 IP 库里被标成 Hosting；家宽 VPS 用住宅 IP，标成 Residential。配置、带宽、延迟这些取决于具体套餐，跟“家宽”两个字没有必然关系。

**为什么延迟比普通韩国机房 VPS 高那么多？**
因为线路走法不同。普通韩国机房 VPS 常做的是三网直连优化，延迟能压到 50–80ms；这台机器的移动和教育网线路确实直连，但电信回程要绕德国法兰克福、联通回程绕美或欧洲，所以电信联通用户测出来的数字会明显高于机房 VPS。这不是机器性能问题，是路由问题。

**住宅 IP 会不会用着用着变了？**
官网标的是静态 IP，长期不变。这也是它比动态住宅 IP 更适合账号运营的原因——IP 频繁变更本身就是风控信号。

**能装 Windows 吗？**
官网写明支持安装 Windows。具体镜像和授权方式在开通后的面板里看。

**1 核 1G 够不够用？**
跑 Docker、代理软件、指纹浏览器、轻量脚本够用。要同时开多个浏览器实例或者跑数据库，直接上 2 核 2G 以上。
